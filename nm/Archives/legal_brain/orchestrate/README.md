## Boundaries

This is not a fixed sequence through the folders. Factories install explicit tool populations; filenames do not grant authority. Parent/child scope, budget and permission checks remain native owners. turn.py remains the legacy turn path; reorganisation does not silently substitute the controlled brain for every client matter.

Architectural roles and dependency directions remain explicit in
[`nm/source_layout.json`](../../../source_layout.json). No new tool permission,
provider-processing approval or release claim comes from moving a file.
