# 03.08 — Measure and replay controlled execution

Run the existing admitted private evaluation and repair transport, capture runtime observations and replay exact recorded inputs/results without reclassifying historical results as current acceptance.

This is a responsibility within the legal-brain loop, not a mandatory execution
stage or a claim of complete feature acceptance. Files inside this folder stay flat.

## Boundaries

Private fictional previews are not client advice or release. A source move creates no evaluation approval, renewal, budget increase or paid-model permission. Runtime tapes and replay captures are execution observations, not new facts, legal sources or PASS certificates.

Architectural roles and dependency directions remain explicit in
[`nm/source_layout.json`](../../source_layout.json). No new tool permission,
provider-processing approval or release claim comes from moving a file.
