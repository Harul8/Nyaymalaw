# 03.05 — Check support and publication boundaries

Check exact candidate words and their actual evidence packages for grounding, quotations, consistency, duties, relevance, independent review and final publication conditions.

This is a responsibility within the legal-brain loop, not a mandatory execution
stage or a claim of complete feature acceptance. Files inside this folder stay flat.

## Boundaries

Receipts cannot be authored clean by a model or inferred from absence. Independent semantic review does not substitute for source currentness, professional review, permission or atomic persistence. Private candidate publication is not automatic normal-client cutover. Communication checks verify wording; they do not create a second communication pipeline.

Architectural roles and dependency directions remain explicit in
[`nm/source_layout.json`](../../source_layout.json). No new tool permission,
provider-processing approval or release claim comes from moving a file.
