# 03.06 — Explain and present checked work

Present proportionate, natural advocate-facing responses, supporting passages and references; render the matter workspace, source reader, safe progress and separately admitted reviewed previews.

This is a responsibility within the legal-brain loop, not a mandatory execution
stage or a claim of complete feature acceptance. Files inside this folder stay flat.

## Boundaries

Presentation exposes checked explanations and useful source linkages, not private chain-of-thought or unsupported draft work. Reviewed previews remain read-only and separately admitted. Progress is safe journal-derived metadata, not evidence that legal reasoning has passed.

Architectural roles and dependency directions remain explicit in
[`nm/source_layout.json`](../../source_layout.json). No new tool permission,
provider-processing approval or release claim comes from moving a file.

## Complete file index

Navigation over 11 implementation files, 4 browser assets and
the package initializer; this is not test evidence.

### Implementation

- [compose.py](compose.py) — Tells the checked findings as one natural reply, checks its words, and carries anything it misses.
- [loop_progress_api.py](loop_progress_api.py) — Read-only authenticated progress from the sealed matter journal.
- [loop_progress.py](loop_progress.py) — Safe stages from a committed journal, never model text or legal advice.
- [preview_display.py](preview_display.py) — Sealed private display acknowledgements, never client delivery or truth.
- [preview_seen_api.py](preview_seen_api.py) — Empty-body authenticated private display acknowledgement; no wording input.
- [preview_seen.py](preview_seen.py) — Records that an advocate viewed a checked preview in the matter journal.
- [register_contracts.py](register_contracts.py) — Keeps advocate-facing language in a professional peer register.
- [reviewed_preview_api.py](reviewed_preview_api.py) — Separate authenticated read of checked fictional preview, never raw private work.
- [reviewed_preview.py](reviewed_preview.py) — Reads saved, verified wording for a fictional-matter preview without publishing it.
- [tool_submit_answer.py](tool_submit_answer.py) — Proposes answer wording for checks; it does not publish it.
- [working_explanation.py](working_explanation.py) — Projects the private rationale without making it a second legal answer.

### Browser assets

- [loop-progress.js](loop-progress.js) — Shows the working word while a reply is prepared, chosen by the recorded stage; no panel.
- [matter-workspace.css](matter-workspace.css) — Styles the matter workspace, board, chat and contextual tools.
- [matter-workspace.js](matter-workspace.js) — Served matter projections and explicit commands, opened from the file icon's Matter records.
- [source-reader.js](source-reader.js) — Read a released saved passage; never resolve a label or start legal research.

- [__init__.py](__init__.py) — Legal-brain communicate capability; no runtime exports.
