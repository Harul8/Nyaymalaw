# Advise

Advice, available options, relief, reservations and attributed decisions. These contracts and services consume the existing legal-brain/release and file-currentness owners; this folder is not another verifier or source registry.

Key files:

- [options.py](options.py) — Builds options through the existing option contracts.
- [relief.py](relief.py) — Owns relief-related advice preparation.
- [reassessment.py](reassessment.py) — Links advice and decisions to the shared file dependency ledger.
- [turn_receipt_contracts.py](turn_receipt_contracts.py) — Types the saved released interaction receipt rather than a new model-authored verdict.
