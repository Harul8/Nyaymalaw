The answer, counsel-brief and released-turn receipt contracts the served engine uses. The earlier options, relief, reassessment and decision modules were deleted on 19 Oct 2026 (P24); this folder is not another verifier or source registry.

Key files:

- [turn_receipt_contracts.py](turn_receipt_contracts.py) — Types the saved released interaction receipt rather than a new model-authored verdict.
