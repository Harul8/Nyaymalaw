# 04 — Work the file

Source-bound disputes, attributed assertions, recorded event readings, corrections and private file proposals. Preserve original history and typed dependency currentness; an assertion or private deadline candidate is not a confirmed finding or established legal deadline.

Key files:

- [file_mutation.py](file_mutation.py) — Prepares native checked mutations; persistence remains with the actual loop/store transaction.
- [dependency.py](dependency.py) — Owns dependency versions, recorded-event populations and invalidation.
- [original_instruction.py](original_instruction.py) — Reconstructs authenticated original supplied instructions from actual saved history.
- [deadline_proposals.py](deadline_proposals.py) — Derives append-only conditional deadline/calendar candidates without verified on-dates.

## Current file index

This index follows the shipped [source-layout manifest](../source_layout.json). The semantic roles below retain the existing dependency boundary; the journey folder is not a permission or acceptance claim.

### Services and native owners

- [board_note.py](board_note.py) — The note under a reply: what the saved file gained from the message, and removals waiting for the advocate.

- [deadlines.py](deadlines.py) — Maintains the explicit deadline register and its states.
- [dependency.py](dependency.py) — Finds which conclusions a changed input invalidates without disturbing unrelated work.
- [dispute_agenda.py](dispute_agenda.py) — Derives an agenda across disputes for the conversation and matter board.
- [evidence_item.py](evidence_item.py) — Types and assembles the evidence inventory.
