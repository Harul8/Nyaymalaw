# Work the file

Source-bound disputes, attributed assertions, recorded event readings, corrections and private file proposals. Preserve original history and typed dependency currentness; an assertion or private deadline candidate is not a confirmed finding or established legal deadline.

Key files:

- [file_mutation.py](file_mutation.py) — Prepares native checked mutations; persistence remains with the actual loop/store transaction.
- [dependency.py](dependency.py) — Owns dependency versions, recorded-event populations and invalidation.
- [original_instruction.py](original_instruction.py) — Reconstructs authenticated original supplied instructions from actual saved history.
- [deadline_proposals.py](deadline_proposals.py) — Derives append-only conditional deadline/calendar candidates without verified on-dates.
