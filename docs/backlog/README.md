# Historical planning registries and retained evidence

Owner decision P12 on 10 October 2026 retired the PRD/backlog planning registry
as the owner of new work. Use **Advocate build plan** in
`docs/Nyaymalaw_Implementation_Plan.xlsx` for current decisions, slice contracts,
sequence, implementation status and evidence. The legal brain sheet supplies
capability intent; Before Build is historical.

`steps.yaml`, `plan.json`, `status.yaml`, `professional.json` and their schemas
remain at these paths because retained assurance and corpus-measurement tools
read them. Do not remove them or add new core-engine status to them merely to
make an old projection green. `build_rules.json` still records retained build
method checks; it does not select new feature work.

The dated reports and `evidence/` directory preserve the work they actually
measured. A past passing result cannot certify a rebuilt engine. Keep original
evidence and its dependencies; do not relabel it as current acceptance.

The [planning archive map](../../development_environment/archives/planning-20261010/README.md)
lists exact consumers and the old evaluation scripts that were moved. It is a
custody inventory, not a second work queue.
