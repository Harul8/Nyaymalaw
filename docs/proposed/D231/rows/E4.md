# E4 - Summarization engine

Row 39 of the 'Advocate build plan' sheet, written out by plan_export.py. The sheet is the record (P7).

## ID

E4

## Item

Summarization engine

## Description

Summarises a judgment or document faithfully: facts, issues, holdings, reasoning and directions kept apart; submissions kept apart from the court's own reasoning; each point linked to its paragraph; negations, amounts, dates and conditions preserved; unreadable parts named.
POC: judgment summaries checked point by point against the source paragraphs.
Wired: 'explain this judgment' (A6) and bundle summaries (B3) in the existing chat.
Production: pass bar on a fixed judgment set.

## Governs or depends on

E1 for authority references; E6 for uploaded material; S3 review/release; 3.4.2-3.4.4, 6.1.9
