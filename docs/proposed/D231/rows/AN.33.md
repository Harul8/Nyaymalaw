D18 CHECK WITHOUT DELETING. Code ignores only what cannot change meaning (spacing, a word a scan split, case, quotation marks, stops between letters; anything touching a digit is compared exactly; handwriting the page reader transcribes inside square brackets counts as the page's words). Every other failed check goes to a model with code's evidence (the point, the page's nearest words, why it failed), which decides: a clerical slip (and gives the page's own words), on another page, partly unsupported (only the failing portion is dropped), a real difference between papers (kept as a point of its own), or a misread scan (the page is read again from its image). Code checks what the model gives. What still cannot be checked is kept, marked not verified on the page, and shown. No date is erased.
