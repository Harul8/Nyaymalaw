Retrieval engine

## Description

Find candidate bare-Act sections and judgment passages for each legal question, rank them and return exact source text with context. Fuzzy search ranks; it never decides governing law. The current response pipeline calls nm/core_engine/retrieval.py. Exact account-first enquiries and document identity on every rerank window are built; overall relevance, useful omissions and integrated acceptance remain open under S2/SEQ.3.
