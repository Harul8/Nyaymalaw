## Description

From the actual request and original qualifications, generate distinct legal enquiries, search held Acts and judgments with the hybrid engine, rerank and read back exact passages plus parent/surrounding context. Preserve supporting and adverse material, speaker/treatment ambiguity, temporal/jurisdiction limits, source lineage and partial coverage. Measure relevant omissions as well as irrelevant admissions before widening scope. Retrieval returns candidates; E3 checks legal use.
