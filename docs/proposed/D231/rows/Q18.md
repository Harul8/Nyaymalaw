# Q18 - Orders missing from the held Code of Civil Procedure

Row 197 of the 'Advocate build plan' sheet, written out by plan_export.py. The sheet is the record (P7).

## ID

Q18

## Item

Orders missing from the held Code of Civil Procedure

## Description

The Code of Civil Procedure in the Act store (the India Code build of 19 Oct 2026) holds 171 sections and 585 rules of 48 Orders, but no rule of Orders XV, XX, XXVIII, XXXIIA or XXXIII. Order XX is judgment and decree (Rule 18, the partition decree, is in the 14 Oct answer key). Search cannot find what is not held; whether the source lacks them or the build missed them is not yet known.

## Governs or depends on

P20 (the India Code Act store); P32

## Status

RESOLVED 21 Oct 2026 (owner's authority, O11): the build reads every Order; the Act store rebuilt as acts_v5 and search switched to it. A server started now reads it.
