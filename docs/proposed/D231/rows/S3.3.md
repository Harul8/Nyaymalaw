## Description

Code validates owned IDs, exact quotes, case/statute references and persistence. One independent review examines the complete draft against the requested work and supplied evidence, not just writer-selected snippets. It reports unsupported additions, missed requests, conflicting evidence and misleading framing. Unchecked or rejected material cannot substantiate a claim.
