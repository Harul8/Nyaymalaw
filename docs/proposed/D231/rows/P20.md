# P20 - Re-source the Acts from India Code

Row 174 of the 'Advocate build plan' sheet, written out by plan_export.py. The sheet is the record (P7).

## ID

P20

## Item

Re-source the Acts from India Code

## Description

Where India Code publishes an Act section by section, its sections are fetched and become that Act's text; where it holds only a PDF, or does not hold the Act, our current text stays. Schedules stay ours (India Code holds them only as PDFs). Each fetched section is compared with our text, and wording that differs beyond formatting and amendment notes is shown to the owner before anything is replaced: India Code has errors of its own (s.138's Explanation reads 'debt of other liability').
