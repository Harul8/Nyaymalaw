## Description

Measure exact resolution on held citations separately from identity accuracy. The POC resolution floor is 55%; independently labelled wrong-case, ambiguity, name and quote controls must produce no observed false checked admission. Record false rejections as well as false admissions. Missing/partial indexes produce Could not check. Known bad index mappings are quarantined or marked unresolved; a name-free exact lookup is not proof of a correct linkage. These finite measurements do not promise universal zero error.
