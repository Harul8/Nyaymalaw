## Item

Saving shown sections, and labelled edits

## Description

Each section is saved when it is shown. While the overview is written, the cross-check may correct a section already shown: the correction is reviewed first, the original stays viewable ('see original'), and the section carries a label saying what changed and why; a correction that changes the advice (for example 'can still file' to 'out of time') is also called out at the top of the answer, above 'In short' (P40, 24 Oct 2026). Sections never changed carry no label. The turn is complete when the overview lands; after that nothing earlier is edited - an error found later is corrected in the new reply.
