## Item

Calls and completion

## Description

Account for one transcription request per supported recording or necessary timed chunk; record chunk count, duration, tokens where applicable, latency and cost. Local speech processing makes zero provider calls. Conditional retries consume the shared bound. Normal extraction/response/review calls retain their existing owners; no extra legal-analysis call solely because input was audio. A successful provider response alone does not prove faithful or complete transcription. Release only after source references, coverage and downstream review pass.
