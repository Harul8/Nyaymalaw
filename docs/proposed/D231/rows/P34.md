## Item

A time limit may run from the end of a period the facts set

## Description

A time limit runs from the event the Act's own words name (P23's principle, unchanged). Where that event is the end of a period the advocate's facts set - a credit period, a time agreed for payment or performance - and no message or document dates that end itself, the time-limit step quotes, exactly as written, the date that period runs from (the delivery) and the period as the facts state it ('30 days' credit'); code counts the period's end with the same arithmetic as the Acts' periods, and the Act's period runs from it. The answer and its Working box say how the start was worked out, and that the agreement's own terms may count the period differently. Where either fact is missing, the limit stays not worked out and the advocate is asked for it, as now.
