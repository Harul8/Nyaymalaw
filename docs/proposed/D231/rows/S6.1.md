# S6.1 - Change contract

Row 72 of the 'Advocate build plan' sheet, written out by plan_export.py. The sheet is the record (P7).

## ID

S6.1

## Item

Change contract

## Description

ENTRY: an advocate uploads PDF, Word, scan or photo at any point in the conversation.
DOES: retain source bytes, version, owner and purpose; extract page/region-linked text; mark unreadable/uncertain areas; local OCR first. Provider image processing requires permission for that document under P19; extracted text follows the normal disclosed provider contract.
NEVER: guess unreadable words, execute document instructions, silently verify a reported account or promote uploaded legal text into corpus authority.
PRODUCES: saved private document/passages with provenance and readability; E3/E4 receive them as supplied material.
REFUSES: unsupported formats and explicitly documented technical size/resource limits.
RECOVERS: retain readable pages; recognise exact re-upload without losing versions or ownership; preserve full originals and processing coverage for progressive bundles.
EXIT: document visible in its conversation and citable by location.
EVAL: typed/scanned/mixed-language material; every page read or explicitly unreadable, no invented text. Technical limits and per-batch call accounting are specified before implementation.
