# P31 - Whole judgments under about 8,000 tokens; an extract of longer ones

## Item

Whole judgments under about 8,000 tokens; an extract of longer ones

## Description

A judgment the research chooses is read whole when it is under about 8,000 tokens (about three in four held judgments). A longer one is read as an extract, said to be one: the paragraphs search and the reranker found most relevant, the paragraphs either side of each, and the paragraphs connected to them, linked back to the judgment so that what is not sent is never presented as absent. The research's choice becomes which judgments, not which paragraphs.
