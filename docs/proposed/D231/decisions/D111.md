D111. THE CASE INDEX'S COURT LABEL (extends D102). The case index names the Andhra Pradesh High Court as its source does - "Andhra HC (Pre-Telangana)", 4,289 judgments, 1954-2018 - which the rule the statutes' titles use did not read. The one court rule now reads that label as the Telangana forum's, so the citation check's scope statement says "High Court of Telangana, 1954-2018 (4,289)" and no longer "No Telangana High Court judgments are held"; a library with none still says it.
