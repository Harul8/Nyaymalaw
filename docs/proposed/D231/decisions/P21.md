Item:
Mark repealed Acts as not in force

Description:
An Act we hold that India Code does not list as in force is kept, for older matters, but marked not in force - with the date India Code was checked and, where India Code shows it, the Act that replaced it - so an answer says so rather than citing it as current law.

Governs or depends on:
P13; SEQ.3 (retrieval), SEQ.4 (answers); the held Act store
