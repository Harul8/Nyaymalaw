# D17

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.33](../rows/AN.33.md), Description

D17 READ FOR COMPLETENESS. Each paper is read, with the whole file in view as now, for every legally significant point and not only events: what happened, orders with what they found and what they directed, findings, what each party asserts, admits, denies or alleges, a document's particulars, who is related to whom or acts for whom, and what a paper says is pending, done or still to do. Beside it: the side-by-side reading, now also over the list of everything read; comparisons code sets up from that list for the model to judge; a final pass shown the pages and the list and asked only what is missing; and checks by code that every page and every date, number and name on a page is carried by some point.
