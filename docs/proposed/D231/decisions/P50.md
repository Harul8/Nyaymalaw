The answer's text uses the full width of the window (replaces P45's reading width)

Description:

Style only: no change to what an answer says, how it is saved, its contracts or versions, and no model call; every saved conversation, reopened as saved (P46), shows at the new width. A phone's column, the message box and the advocate's own messages are unchanged.
