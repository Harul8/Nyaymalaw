Description:
When a reviewer withholds a response, that means the response is not grounded in the facts shared. So we should send it back to the model saying this response is not grounded in the data provided or the details shared, and we should ask the model to ground the response in the details and then give a grounded response. And hence the question of withholding a response for the second time should never happen. At most we can do a third try, but at least after the third try a response getting completely withheld should not happen at all. Either we give a grounded response, and if parts of response is not grounded, then we discard that part, and whichever part is grounded we give that response. If the entire answer is not grounded, then we tell the model the answer is not grounded, and then ask the model to ground the answer in the details shared, so that the second time we get a grounded response and we should share it with the user. ... if a response is getting withheld, that means the model is not doing a good job, which is not a user's problem, it is a model's problem, and we should help model address it and come up with the right response. | When the matter is complex and has multiple disputes ...
