Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.37](../rows/AN.37.md), Description

D37 (agreed): THE QUESTION WINDOW. When an answer only the advocate can give would change the work, NM asks it in a window over the workspace: one to four questions, each with a short heading, the question, one line on what depends on the answer, and two to four choices (one, or several ticked); always a box for the advocate's own words, and 'Go on without this', which applies the default NM states. The model proposes questions within steps it already runs; code decides whether one is shown and owns the mechanical triggers; a question that changes nothing is never built (the rule of the declared gate G-GAP). The progress line says NM is waiting for an answer. The answer joins the conversation as the advocate's own words, seen by every later step and by the independent review, and is saved with the turn; reopening shows what NM asked and what was answered exactly as saved (P46). What NM shows of usage is a percentage only (O21; item 6).
