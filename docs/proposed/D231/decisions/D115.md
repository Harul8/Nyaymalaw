## From [AN.45](../rows/AN.45.md), Description

D115. THE PAID NAMING OF THE UNKNOWN KINDS (45h). A judgment's passages are read in order in windows of about twelve thousand tokens, each unknown passage in the words around it, by 6 Luna at medium effort; the kinds are facts, arguments, reasoning, ratio, order, headnote, other, and unclear (the passage stays unknown). The default is an estimate; a run needs the owner's spend limit; labels go to a side file; apply (server stopped) writes a kind only where the passage is still unknown and says who named it; undo puts them back. Estimated from the 300-judgment trial store at Luna's price with no discount for the repeated prompt: about $64 for the library; a first run of 30 windows about four cents.
