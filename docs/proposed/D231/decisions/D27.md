## From [AN.33](../rows/AN.33.md), Description

D27 NO HARD LIMITS. "we should not put any hard limits, unless it may create never ending loop, we never know how complex future cases can be" - no step's work is cut short by a fixed allowance: every model call may write as much as its model can (each step's output allowance is the model's own most, which the adapter never exceeds for a model that writes less), and no list a model is asked about is cut to a number; what bounds a loop (the rounds of repair, the trims, the corrections of a turn, the reading again in halves) stays.
