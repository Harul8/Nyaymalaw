# D134

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.48](../rows/AN.48.md), Description

D134. STEP BY STEP, STOPPING AT EVERY STEP. A message is worked one step at a time, and NM stops after each step for the advocate's go-ahead or feedback. NM's own questions stop and wait for the answer too: no default is applied after a wait. For a matter the steps are: (1) read the papers sent and understand what is asked; (2) the disputes, put on the matter board for review; (3) for a dispute the advocate chooses, its legal questions; (4) that dispute's research; (5) its written analysis, checked and reviewed as today. Each step after the first runs only on the advocate's go-ahead.

## From [AN.58](../rows/AN.58.md), Description

D134 stands: a message is worked step by step, stopping for the advocate's go-ahead after each step, first messages and follow-ups alike; Claude's recommendation that follow-ups run end to end is not taken. Two exceptions, each read from the advocate's own message by the model, never by keywords (the owner's rule of 13 Oct: understanding is the model's): (a) the message says plainly to do the work end to end, straight through without stopping; (b) the message asks for one specific thing - a question answered, a document drafted, a point looked up - rather than a matter to be worked through. Then the message runs end to end from the start, and code says so in its own words as the work begins, with the model's reading after it, marked as NM's reading, so that the advocate can stop it. Where the reading fails or is unclear the message is worked step by step - the default, which stops before research is paid for. At a stop a message is read as today (48c), which already takes 'end to end' and a go-ahead for named disputes. How: one short reading on the turn's model at the start of a message sent step by step (message_reader, not a pinned piece), about $0.001 a message on Luna.
