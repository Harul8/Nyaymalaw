D181. THE CASE ACCOUNT IS GATHERED WHERE IT IS WRITTEN. A new version of the case step asks for the same account in a gathered form: the requirements under a few headings of the model's own choosing for that dispute, as the dispute needs (no number is imposed); each point of the other side tied to the heading it attacks; the things to get gathered by who can give them, so that one request covers every requirement it serves; and the few things that most decide the dispute as the papers stand. These are judgments of meaning, left to the model; the second call still checks the account against the sources and corrects it (the loop of AN.35 is kept, no call is added). Code checks afterwards what is mechanical: every heading and reference exists, every requirement sits under one heading, every ask names the requirements it serves, and nothing of the account is lost between the first call and the gathered form. A case saved before this version is shown as saved, ungathered (P46).
