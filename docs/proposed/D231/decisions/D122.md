# D122

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.46](../rows/AN.46.md), Description

D122. APPEND, NOT REBUILD (the owner: ok). Only the new documents are turned into vectors. The new index file is the old file's vectors plus the new ones; the passage rows are appended at the next positions; the word index is rebuilt (the library is immutable once built); the lineage record and its verified block are updated; the earlier index, rows and record are kept beside it for roll-back. Nothing is re-encoded. It becomes live at one planned restart, before the index opens (the index is memory-mapped on Windows and cannot be replaced while the server runs), and only when no turn is running. Delta segments searched alongside the main set (a true in-place append) are NOT built; they are revisited only if additions become frequent.
