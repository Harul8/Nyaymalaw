# D146

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.48](../rows/AN.48.md), Description

D146. A MESSAGE WHILE NM WAITS (owner: "your recommendation"). While NM waits on a matter, a message is taken as part of the matter in hand - information added, a dispute named, or go ahead - and NM says how it took the message, so that the advocate can correct that. A new, unrelated question waits until the advocate finishes the matter.
