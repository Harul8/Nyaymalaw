# D3

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.28](../rows/AN.28.md), Description

D3 The model reads, code verifies. For a date, an extent, a document number or a name, the model gives its reading and the exact words it read it from; code checks that the words are on the page and that every number in the reading is in them, and reads them itself where it knows the form; a disagreement goes to the second look (D2), never a silent choice. Code's list of forms decides how much is confirmed, never what is right.
