# D183

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.49](../rows/AN.49.md), Description

D183. SEVERAL THINGS ANSWERED IN ONE REPLY. One button on a dispute, 'Tell NM about these', opens the answers window that 'What I need from you' already uses (AN.37, D37, D43), with one row for each gathered ask (D181) or, for a case saved earlier, each requirement not yet shown. Each row takes what the advocate has, does not have or will get, in their own words; one message is sent, in the wording the single buttons use today. No new route and no new model step.
