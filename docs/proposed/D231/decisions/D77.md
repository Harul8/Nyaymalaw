# D77

Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.42](../rows/AN.42.md), Description

D77. The queue: one line per message just above the message box (no longer under the progress in the conversation), each with Steer, Edit and Discard. Edit puts the message back in the box, above anything typed there, with its files; Discard removes it. A message whose files are still being read says so on its line and waits for them before it can be steered or sent (AN.40). The queue is saved with the conversation and survives a reload (Claude's proposal, not changed by the owner: no work is ever lost). A queued message never goes in another conversation (AN.40 D64).
