Written out from the Advocate build plan by plan_export.py; the sheet is the record (P7).

## From [AN.46](../rows/AN.46.md), Description

D117. WHO IS AN ADMIN (the owner: ok). The server's settings name them, NM_ADMINS="email:admin,email:view-only", read at start. Never a field on an account file, never settable over HTTP, never from the Admin pages. An entry whose level is not one of the two is ignored (a typo locks someone out; it can never raise anyone) and counted for the diagnostics. For anyone not named, every admin address answers 404 as if it did not exist, and the person menu does not show Admin.
